# Historical research

This directory contains the methodology and evidence metadata for Compile Through Time. Published workspace snapshots live in `../scenarios`; redistributable captures belong in `../assets`.

The project asks: **What did a developer actually see when pressing Compile, Build, or Run in a given year?** A workspace snapshot is publishable only when its visible claims are traceable to evidence or explicitly marked as simulated.

See [methodology.md](methodology.md) and [fidelity-levels.md](fidelity-levels.md).
