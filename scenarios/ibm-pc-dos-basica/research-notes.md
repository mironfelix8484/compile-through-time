# BASICA on the IBM PC

## Frozen environment

IBM Personal Computer with an 8088 processor, IBM PC DOS 2.10, and IBM Advanced BASIC A2.10 in 80×25 CGA text mode. The in-memory program consists of two numbered lines and is invoked with the direct-mode `RUN` command or the F2 soft key.

## Claim-to-evidence matrix

The IBM BASIC manual supports numbered program lines, direct-mode commands, `RUN`, the return to the `Ok` prompt, and the function-key command strip. Contemporary version records support BASICA A2.10 shipping with PC DOS 2.10 in 1983.

## Normalizations

The program is project-created. Free-memory count is fixed to a representative 60300 bytes. The display uses CSS colors and a system fixed-width font rather than redistributing an IBM ROM font.

## Known gaps

No matching IBM PC, PC DOS 2.10, and BASICA A2.10 execution has been captured. Exact glyphs, memory count, banner wrapping, cursor shape, display phosphor, and screen geometry remain simulated.
