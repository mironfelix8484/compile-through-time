# Turbo Pascal 6.0 on MS-DOS 5

## Frozen environment

MS-DOS 5.0, English, x86, in 80×25 VGA color text mode with Turbo Pascal 6.0. The active source file is `C:\TP\HELLO.PAS`; compilation targets memory before the program is run.

## Claim-to-evidence matrix

The Borland Turbo Pascal 6.0 User's Guide supports the text-window IDE structure, Compile/Compile with Alt-F9, Run/Run with Ctrl-F9, the fields shown during compilation, and the separate User Screen.

## Normalizations

The source file and program are project-created. Available memory and line count are fixed representative values. The browser uses a fixed-width system font and CSS VGA colors instead of redistributing a proprietary DOS font or Borland artwork. The reconstruction has no wallpaper or graphical desktop.

## Known gaps

No matching MS-DOS 5 and Turbo Pascal 6.0 VM execution has been captured. Exact glyph shapes, character-cell geometry, menu spacing, compilation values, and the timing of screen transitions remain simulated.
