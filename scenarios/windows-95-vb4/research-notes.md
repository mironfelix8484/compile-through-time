# Visual Basic 4.0 on Windows 95

## Frozen environment

Windows 95 Retail, English, x86, at 1024×768 with Microsoft Visual Basic 4.0 Professional Edition (32-bit). Project1 is a Standard EXE with Form1 as its startup form and a CommandButton Click event that displays a message box.

## Claim-to-evidence matrix

The Visual Basic user guide supports the Form Designer, controls and Properties workflow, event procedures, Run > Start, the toolbar Start button, F5, and the distinction between design time and run time.

## Normalizations

Project1, Form1, Command1, source, placement, timestamps, and desktop arrangement are project-created. All desktop, icon, form, and dialog visuals are CSS or vector approximations rather than Microsoft artwork.

## Known gaps

No matching Windows 95 and Visual Basic 4.0 VM execution has been captured. Exact toolbox icons, window geometry, property ordering, menu contents, fonts, and run-mode transitions remain simulated.

## Review history

Initial simulated reconstruction prepared as the seventh museum workspace.
